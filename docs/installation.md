# Installation

**NOTE:** You must have git installed. If you don't have it, install it from here https://git-scm.com/.

## With pip & Git

```shell
# For Windows
py -3 -m pip install git+https://github.com/RickSteadX/mangadex-downloader.git

# For Linux / Mac OS
python3 -m pip install git+https://github.com/RickSteadX/mangadex-downloader.git
```

The package is installed as `mangadex-downloader-rsx`.

## From a local clone

```shell
git clone https://github.com/RickSteadX/mangadex-downloader.git
cd mangadex-downloader
pip install .
```
